# Sree Surabhi Dairy

A premium, responsive marketing website for Sree Surabhi Dairy — built with React, TypeScript, and Vite.

## Sections

Sticky header, hero carousel, about, products, farm-to-home process timeline, quality & purity, why-choose-us, testimonials, gallery with lightbox, presence/contact, and footer.

## Stack

- React 19 + TypeScript
- Vite
- Framer Motion (scroll reveals, hero carousel)
- lucide-react (icons)

## Getting started

```bash
npm install
npm run dev      # start the dev server
npm run build    # type-check and build for production
npm run preview  # preview the production build
```
